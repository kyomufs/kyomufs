Third-year **Applied Informatics** student at Tula State University, major *Intelligent and Domain-Oriented Automated Systems*. I run NixOS as a daily driver and keep the whole machine as a single reproducible flake. Most of what I build sits between infrastructure and tooling: local-first AI gateways, Wayland desktop shells, Go services and Flutter apps.

- **Systems & infrastructure** — NixOS, Linux, Docker, Caddy, Gitea, Git; declarative configs over manual setup
- **Network operations** — segmenting home and lab networks across KeeneticOS, RouterOS and OpenWrt
- **AI engineering** — agent harnesses (Copilot, Hermes, OpenCode, Crush, DeepSeek Harness), custom LoRA fine-tunes
- **Mobile & desktop** — Flutter/Dart, Kotlin with Jetpack Compose, QML for Quickshell panels
